# Ignyx Documentation

Ignyx is a high-performance Python framework powered by a Rust core for teams building APIs, AI services, and production systems that need speed without sacrificing developer experience.

[Return to the main website](https://sakethdevx.github.io/ignyx)

## New In 3.1

- Modern Scalar API docs at `/scalar`, alongside Swagger UI and ReDoc.
- Built-in `Page[T]` and `paginate()` helpers for limit/offset pagination.
